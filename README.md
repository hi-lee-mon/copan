# コパン（COPAN）

> **コパンは、パン好きが現在地や投稿を通じて、まだ知らないパンと出会い、記録・共有するためのパン特化型サービスです。**

機能を検討するときの判断基準は、常にこれ。

> **「この機能は、パンとの新しい出会いを増やすか？」**

**名前の由来**: フランス語 *copain*（仲間）の語源は後期ラテン語 *compāniō* = **com-（共に）+ pānis（パン）**、すなわち「パンを分け合う相手」。英語 *companion* も同語源。

## アーキテクチャ（決定済み）

```text
┌─────────────────────────────────────────┐
│  Cloudflare = 配信層                     │
│  ・フロントエンド（Next.js）              │
│  ・画像の保存と配信（R2）                 │
│  ・地図タイルの配信（R2）                 │
│  ・CDN / DNS / レート制限・WAF            │
└─────────────────────────────────────────┘
                  ↕
┌─────────────────────────────────────────┐
│  AWS = 計算層                            │
│  ・Go の API（Lambda / VPC外）            │
│  ・Lambda Function URL                   │
└─────────────────────────────────────────┘
                  ↕
┌─────────────────────────────────────────┐
│  データ層（AWSの外）                      │
│  ・PostgreSQL + PostGIS                  │
│  ・v0.1: Neon → v1.0前に東京リージョンへ   │
└─────────────────────────────────────────┘
```

| 領域 | 採用 |
| --- | --- |
| バックエンド | **Go**（Lambda / Function URL） |
| フロントエンド | **Next.js**（TypeScript） |
| API契約 | **TypeSpec → OpenAPI → 両側コード生成** |
| データベース | **PostgreSQL + PostGIS**（v0.1 は Neon） |
| 画像・地図タイル | **Cloudflare R2**（署名付きURLで直接アップロード） |
| リポジトリ | **Turborepo によるモノレポ** |

**なぜこの構成なのかは、すべて [ADR](./docs/adr/) に記録されている。**

## 開発上の約束

- 実装は**開発者本人**が書く。AIはチケット作成・ヒント・レビューに徹する（[ADR 20260812-0905](./docs/adr/20260812-0905-development-workflow.md)）
- 作業は**チケット単位**で進める
- 実装は **TDD** で進める
- コードには `How`、テストコードには `What`、コミットログには `Why`、コードコメントには `Why not` を書く
- **意思決定をしたら `docs/adr/<yyyymmdd-hhmm>-<name>.md` を作成する**
- DBの移行可能性を保つため、[特定サービスの固有機能に依存しない](./docs/tech-decision-guide.md#実装時に守る制約)
