# チケット

**実装を進める単位。** 本業の合間に進めるため、1回の作業セッションで完結する粒度に切る。

役割分担とチケット運用の根拠は [ADR 20260812-0905](../adr/20260812-0905-development-workflow.md) を参照。

## 運用ルール

- **実装は開発者本人が書く。** Claude Code はチケット作成・ヒント・レビューに徹する
- **チケットは着手する直前に作る。** まとめて先に作らない（先のチケットは前の決定に依存するため、事前調査がすぐ陳腐化する）
- 1枚あたり **2〜3時間**、週5時間なので **週1〜2枚**が目安
- ファイル名は `NNN-<内容がわかる名前>.md`（連番）
- 書式は [TEMPLATE.md](./TEMPLATE.md)
- **完了したら「振り返り」を自分で書く。** 見積と実績のズレを残し、次の見積精度を上げる
- **「不足情報TODO」が決定事項になったら ADR を作る**（[adr/README.md](../adr/README.md) の書式に従う）

## ステータス

`未着手` → `進行中` → `完了`
