# 001: 「コパン／COPAN」の商標・ドメインを実査し、名称を確定する

- ステータス: 未着手
- 見積: 2h / 実績: -h
- 依存: なし
- 関連: [ADR 20260811-2003 プロダクト名](../../adr/20260811-2003-product-name.md)、[要件定義 11. 未決事項 #0](../requirements.md#11-未決事項)

## 1. 目的

「コパン／COPAN」を使い続けてよいかを判断し、ドメインを確保する（または確保しない判断を記録する）。

## 2. 背景

要件定義で **最優先** に置かれた未決事項。

前身の「パント（PANTO）」は、**同業種に実在するベーカリーブランドと正面衝突していた**ため却下された（[ADR 20260811-2003](../../adr/20260811-2003-product-name.md)）。COPAN については同等の検証がまだ行われていない。

**実装を始めてから名前を変えると、波及範囲が跳ね上がる。** リポジトリ名、Goのモジュールパス、npmパッケージ名、R2バケット名、ドメイン、Cloudflare/AWSのリソース名がすべて連動する。だから最初のチケットに置いている。

## 3. 事前調査

> ここは「答え」ではなく「調べる入口」。判断は自分で下す。

### J-PlatPat（特許情報プラットフォーム）

特許庁が運営する無料の検索システム。商標の出願・登録状況を誰でも調べられる。
使うのは **商標検索** の機能で、検索軸は主に3つある。

| 軸 | 内容 |
| --- | --- |
| 商標（文字列） | 「コパン」「COPAN」そのもの |
| **称呼（読み）** | **日本の商標実務ではこれが重要。**「コパン」に近い読みは類似と判断されうる |
| 区分 | どの商品・役務の分野で権利が主張されているか |

### 区分（ニース分類）

商標権は「あらゆる分野で名前を独占できる権利」ではなく、**指定した商品・役務の区分の中でのみ効力を持つ**。だから区分が違えば同じ名前が共存していることがある。

COPAN が確認すべき区分は次の2つ。

| 区分 | 対象 | COPANとの関係 |
| --- | --- | --- |
| **第9類** | ダウンロード可能なアプリケーションソフトウェア等 | アプリとして配布する場合 |
| **第42類** | SaaS の提供、ソフトウェアの設計・開発等 | Webサービスとして提供する場合 |

`docs/requirements.md` が第9類・第42類を挙げているのはこのため。

### 見るべき論点

- **「権利を取る」ことと「他人の権利を侵害しない」ことは別問題。** このチケットの目的は後者。登録するかは別途判断する
- パンという商品分野（第30類など）に COPAN ブランドが実在する場合、区分が違っても**サービス名として紛らわしい**という実務上の問題は残る。PANTO の却下理由はまさにこれだった
- ADR 20260811-2003 が PANTO について行った検証項目（同業種の実在ブランド／他言語での否定的語義／日本語の別語義／同名アプリ）を、COPAN にもそのまま適用する

### ドメイン

- `.app` は Google が運営する TLD で、**HSTS preload に登録されているため HTTPS 必須**。証明書が無いと一切アクセスできない
- 空き確認は whois、または各レジストラの検索
- 取得先によって初年度価格と更新価格が違う。**更新価格で比較する**

> **注意**: 商標の最終的な侵害リスク判断は法律判断にあたる。グレーだった場合は、判断を急がず弁理士への相談を選択肢に入れる。このチケットの成果物は「調べた事実」と「その時点の判断」であって、法的な保証ではない。

## 6. 実装ステップ

調査チケットのため TDD ではない。**記録を残しながら進める**ことを重視する。

1. J-PlatPat で「コパン」を **称呼検索**、第9類・第42類で絞る。結果をメモ
2. 同じく「COPAN」で検索
3. 区分を外して全区分で検索し、**パン・飲食分野に COPAN が無いか**を確認
4. 一般検索で、実在する COPAN ブランド（特に食品・飲食）を確認
5. 主要言語での COPAN / コパンの語義を確認（否定的な意味が無いか）
6. App Store / Google Play で同名アプリを確認
7. ドメインの空きと更新価格を確認
8. 結果と判断を ADR に記録する
