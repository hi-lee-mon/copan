## 1. 目的

「コパン／COPAN」に **致命的な商標衝突が無いこと** を確認し、この名前で実装を進めてよいかを判断する。

**名称の最終確定と、ドメイン・SNS アカウントの確保は、このチケットの範囲外**（v1.0 公開前に別チケットへ）。理由は次節。

## 2. 背景

### なぜ「確定」を後ろに倒したか

当初このチケットは名称の確定まで含めていた。「実装開始後のリネームは波及範囲が大きい」という前提に立っていたためだが、**v0.1 は非公開・自分専用**（[要件定義 スコープ](../requirements.md)）であり、その前提は現段階では成り立たない。

| 対象 | v0.1 段階での変更コスト |
| --- | --- |
| Go module path | `go.mod` 1行 + import の一括置換 |
| npm パッケージ名・スコープ | `package.json` の書き換え |
| リポジトリ名 | GitHub 側の設定変更（リダイレクトも張られる） |
| R2 バケット名・AWS リソース名 | 中身が自分の画像だけなので作り直せる |
| DB のデータ | 影響なし（名前はスキーマに入らない） |
| **ドメイン・SNS アカウント** | **早い者勝ちで不可逆。ただし取得しなければ発生しない** |

コストが跳ね上がるのは **公開して外部に URL が出回ってから**。それは v1.0 の話である。

### なぜ「調査」は倒せないか

商標の衝突が v1.0 の公開直前に判明するのが最悪のパターンで、そのときは露出準備が済んでいて手戻りが最大になる。

**調査は今なら 1.5h、後回しにして NG が出れば手戻りは数週間。** この非対称性があるため、調査だけは先に潰す。

前身の「パント（PANTO）」は、同業種に実在するベーカリーブランドと正面衝突していたため却下された（[ADR 20260811-2003](../adr/20260811-2003-product-name.md)）。COPAN について同等の検証を行うのがこのチケットである。

## 3. 事前調査

> ここは「答え」ではなく「調べる入口」。判断は自分で下す。

### J-PlatPat（特許情報プラットフォーム）

特許庁が運営する無料の検索システム。商標の出願・登録状況を誰でも調べられる。
使うのは **商標検索** の機能で、検索軸は主に3つある。

| 軸 | 内容 |
| --- | --- |
| 商標（文字列） | 「コパン」「COPAN」そのもの |
| **称呼（読み）** | **日本の商標実務ではこれが重要。**「コパン」に近い読みは類似と判断されうる |
| 区分 | どの商品・役務の分野で権利が主張されているか |

### 区分（ニース分類）

商標権は「あらゆる分野で名前を独占できる権利」ではなく、**指定した商品・役務の区分の中でのみ効力を持つ**。だから区分が違えば同じ名前が共存していることがある。

COPAN が確認すべき区分は次の2つ。

| 区分 | 対象 | COPANとの関係 |
| --- | --- | --- |
| **第9類** | ダウンロード可能なアプリケーションソフトウェア等 | アプリとして配布する場合 |
| **第42類** | SaaS の提供、ソフトウェアの設計・開発等 | Webサービスとして提供する場合 |

`docs/requirements.md` が第9類・第42類を挙げているのはこのため。

### 見るべき論点

- **「権利を取る」ことと「他人の権利を侵害しない」ことは別問題。** このチケットの目的は後者。登録するかは別途判断する
- パンという商品分野（第30類など）に COPAN ブランドが実在する場合、区分が違っても**サービス名として紛らわしい**という実務上の問題は残る。PANTO の却下理由はまさにこれだった
- ADR 20260811-2003 が PANTO について行った検証項目（同業種の実在ブランド／他言語での否定的語義／日本語の別語義／同名アプリ）を、COPAN にもそのまま適用する

> **注意**: 商標の最終的な侵害リスク判断は法律判断にあたる。グレーだった場合は、判断を急がず弁理士への相談を選択肢に入れる。このチケットの成果物は「調べた事実」と「その時点の判断」であって、法的な保証ではない。

## 7. 実装ステップ

調査チケットのため TDD ではない。**記録を残しながら進める**ことを重視する。

1. J-PlatPat で「コパン」を **称呼検索**、第9類・第42類で絞る。ヒット件数と、該当があれば「誰が」「どの区分で」「何の役務に」取っているかを記録
2. 同じく「COPAN」で検索
3. 区分を外して全区分で検索し、**パン・飲食分野に COPAN が無いか**を確認
4. 結果と判断を ADR に記録する

### ステップ1〜3で特に注意して見る点

「4. 調査済みの事実」を踏まえ、次の2つが焦点になる。

- 第9類・第42類の称呼「コパン」に、**「毎日を楽しむアプリCopan」の運営者**が権利を持っていないか
- 全区分の飲食・食品分野に、**「生麺パスタコパン」の運営者**を含む登録が無いか
