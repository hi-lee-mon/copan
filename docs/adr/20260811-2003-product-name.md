# プロダクト名を「コパン（COPAN）」とする

- ステータス: 承認
- 日付: 2026-08-11 20:03

## コンテキスト

パン特化型の発見・記録サービスの名称として、以下の2案が候補に挙がった。

| 案 | 由来 |
| --- | --- |
| **パント（PANTO）** | 「パンと共に」 |
| **コパン（COPAN）** | 「ご飯」との掛け言葉、およびフロントエンドの co-location と pan を組み合わせた造語 |

名称は後から変更するコストが最も高い要素のひとつであるため、以下を調査した。

- 同一・近接業種における既存ブランドの有無
- 他言語における意味、特に否定的な語義の有無
- 日本語における別語義
- 同名アプリの存在

## 決定

**プロダクト名を「コパン（COPAN）」とする。**

## 理由

### 1. PANTO は同業種の実在ブランドと正面衝突する

**株式会社PANTO** が運営するベーカリーブランド「PANTO（ぱんと）」が実在する。

- 国産小麦・米粉・無添加を掲げるパン屋
- 北海道（旭川・北見）・青森・和歌山に展開、2025年1月に全国8店舗の展開を完了
- 公式オンライン通販あり、PR TIMES・テレ東プラス等でメディア露出あり
- 2026年5月時点でも新店舗のニュースがあり、拡大中
- 独自ドメイン `panto-bakery.com` を運用

さらに同社は理念として「**パンと人」「パンと地元」「パンと素材」をつなぐ**を掲げており、**命名の由来まで一致している**。

これにより次の問題が生じる。

1. **商標リスク** — 食品（第30類）とアプリ（第9類・第42類）は区分が異なるため直ちに侵害となるとは限らないが、「パンに関するサービス」で PANTO を名乗れば需要者の混同を招くおそれが高く、紛争時に不利な立場に置かれる
2. **検索での不利** — 「PANTO パン」の検索結果を当該ベーカリーが占有する。パン特化サービスとして致命的
3. **運用上の混乱** — パン屋を登録するアプリであるため、「PANTO」というパン屋が本サービスに登録される事態が現実に起こる

### 2. PANTO には言語面の問題も重なる

| 言語・分野 | 意味 |
| --- | --- |
| 英語（英国） | `panto` = pantomime の略。加えて "it's a pantomime" は**「茶番・見せかけ」という否定的な意味**を持つ |
| 日本語 | パント = punt（ラグビー・アメフトのキック）。アメフトでは「攻撃権を放棄して蹴る」プレー |
| 国際・物流 | LX Pantos（旧LGグループ、韓国大手物流）。日本にもパントスジャパンが存在 |

サービス名として「茶番」「放棄」という語義を拾うのは避けたい。

### 3. COPAN は語源がコンセプトそのものである

調査の結果、当初の想定（「ご飯」＋ co-location）を超える裏付けが判明した。

> フランス語 **copain**（仲間）← 古フランス語 *compain* ← 後期ラテン語 **compāniō**
> = **com-（共に）+ pānis（パン）** = 「パンを分け合う相手」

英語 *companion*、スペイン語 *compañero*、イタリア語 *compagno* も同語源である。中世においてパンを分け合うことは信頼と友情の証であった。

つまり「co- + pan」という発想は語呂合わせではなく、**歴史的に正しい語源をなぞっている**。「パンを通じて人がつながる」というプロダクトのコンセプトと完全に一致する。

### 4. COPAN には否定的な語義が見つからなかった

調査した範囲で、否定的な意味を持つ言語は確認されなかった。これが PANTO との決定的な差である。

## 検討した代替案と、受け入れるトレードオフ

COPAN も無傷ではない。以下は既知の弱点として受け入れる。

| 対象 | 業種 | 評価 |
| --- | --- | --- |
| ベーカリー コパン（埼玉）、ベーカリー・コパン（大阪八尾）、boulangerie copan（徳島）、COPAIN（東京）、BAKERY & CAFE COPAiN（山形） | パン屋 | **すでに定番の店名**。ただし多数に分散し、支配的な権利者はいない |
| 株式会社コパン（**COPIN**） | スポーツクラブ（岐阜・愛知） | 綴り・業種ともに異なる |
| コパン株式会社 | ゲーム | 業種が異なる |
| 「毎日を楽しむアプリCopan」 | 近所の友達探し系アプリ | 同名かつSNS寄り |
| Copán | ホンジュラスのマヤ遺跡（世界遺産） | 固有名詞。実害は低い |
| COPAN Diagnostics | 医療用スワブ（イタリア発） | 分野が遠い |
| Edifício Copan | サンパウロの著名建築 | 実害なし |

**「パン屋の店名としてありふれている」点が唯一の実質的な弱点**だが、PANTO の「成長中の単一ブランドとの正面衝突」に比べればはるかに軽い。表記とロゴの一貫性でブランドを確立することで対処する。

なお `copan` はスペイン語の動詞 *copar* の三人称複数形にあたるが、日常語として問題になる用法ではない。

## 結果として必要になるアクション

このADRは調査に基づく判断であり、権利関係の確定ではない。以下は別途必須。

- [ ] **J-PlatPat での商標調査** — 「コパン」「COPAN」を第9類（アプリ）・第42類（SaaS）で検索
- [ ] **ドメイン取得** — `copan.app` 等の空き確認と取得
- [ ] **SNSアカウント名の確保**
